# Generic tests
Pre-built, <span style="color:rgb(216, 203, 251)">reusable tests applicable across multiple models</span> or columns.
- <span style="color:rgb(216, 203, 251)">Minimal configuration required</span>; no SQL or Python needed.
## Common generic tests
- **Unique:** ensures <span style="color:rgb(216, 203, 251)">column values are unique</span>.
- **Not null:** checks that <span style="color:rgb(216, 203, 251)">columns do not contain null values</span>.
- **Accepted values:** validates column <span style="color:rgb(216, 203, 251)">contains predefined values</span>.
- **Relationships:** ensures <span style="color:rgb(216, 203, 251)">referential integrity between tables</span>.
# Singular tests
Custome tests for specific logic or conditions not covered by generic tests.
- <span style="color:rgb(216, 203, 251)">Written in SQL for tailored testing</span> to meet unique data needs.
- Powerful for defining <span style="color:rgb(216, 203, 251)">complex conditions or business rules</span>.

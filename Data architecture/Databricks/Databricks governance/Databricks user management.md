We grant permissions from the Databricks Account Console.
# Admin roles
- **Account admin:** can manage workspaces, users and groups, cloud resources and settings.
- **Marketplace admin:** can manage exchanges and listings on the marketplace.
- **Billing admin:** can view budgets and create budget policies.
# Users
Account users can use the account console to view and connect to their workspaces.
# Service principals
Service principals are identities for use with automated tools, running jobs, and applications.
# Groups
Manage several account users or service principals permissions.
# Auto user provisioning
Databricks allow to configure SCIM to auto provision users created on Microsoft Entra ID to Databricks Account Console.

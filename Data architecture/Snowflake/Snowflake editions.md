# Standard
Introductory offering providing <span style="color:rgb(216, 203, 251)">access to core platform functionality</span>.
- SQL Data warehouse.
- Time travel (1 day).
- Automatic encryption of all data.
- Network policies for limiting site access by user IP address.
# Enterprise
It's for <span style="color:rgb(216, 203, 251)">companies with large-scale initiatives</span> looking for more granular enterprise controls.
- Column-level security and data masking policies.
- Extended time travel (up to 90 days).
- Multi-cluster warehouses.
- Materialized views.
- Query acceleration.
- Periodic rekeying of encrypted data.
# Business critical
Offers <span style="color:rgb(216, 203, 251)">specialized functionality for highly regulated industries</span>, especially those with sensitive data.
- Support for PHI data in accordance with HIPAA.
- Support for PCI DSS.
- Support for private connectivity to the Snowflake service using AWS PrivateLink Azure Private Link or Google Cloud Private Service Connect.
# Virtual private Snowflake
Includes all the features of business critical edition, but in a completely separate snowflake environment, <span style="color:rgb(216, 203, 251)">isolated from all other Snowflake accounts</span>.
- Customer dedicated virtual warehouses.
- Customer dedicated metadata store.
